# ⚡ LAZYVIM IDE SHORTCUTS

### 📂 Dateiverwaltung (Neo-tree)
* **Dateibaum öffnen/fokussieren:** `<Space> e`
* **Datei erstellen (im Baum):** `a`
* **Datei löschen (im Baum):** `d`
* **Datei umbenennen (im Baum):** `r`

### 🔍 Suchen & Finden (Telescope)
* **Datei suchen (Fuzzy):** `<Space> <Space>` oder `<Space> s f`
* **Text in allen Dateien suchen (Grep):** `<Space> s g`
* **Zuletzt geöffnete Dateien:** `<Space> f r`

### 🚀 Code-Navigation (LSP)
* **Zur Definition springen:** `gd`
* **Zurückspringen:** `Strg + o`
* **Alle Verweise (References) anzeigen:** `gr`
* **Variable/Funktion überall umbenennen:** `<Space> c r`
