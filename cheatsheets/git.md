git status :: Zeigt den Status der geänderten Dateien an
git add . :: Fügt alle Änderungen zur Vorbereitung für den Commit hinzu
git commit -m "Nachricht" :: Speichert die Änderungen mit einer Nachricht
git push :: Lädt deine Änderungen auf GitHub hoch
git pull :: Holt die neuesten Änderungen vom Server
git diff :: Zeigt die genauen Unterschiede in den Dateien
git log --oneline --graph :: Zeigt die Commit-Historie kompakt an
git branch :: Listet alle Branches auf
git checkout -b branchname :: Erstellt einen neuen Branch und wechselt dorthin
git stash :: Legt aktuelle Änderungen kurz beiseite
git stash pop :: Holt beiseitegelegte Änderungen zurück
git remote -v :: Zeigt den verbundenen Remote-Server an
git checkout . :: ACHTUNG: Verwirft alle lokalen Änderungen im Verzeichnis
git pull :: Lädt die die Einstellungen von GitHub herunter auf das lokale Repo
