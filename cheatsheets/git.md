git diff :: Zeigt die genauen Unterschiede in den Dateien (was wurde geändert?)
git log --oneline --graph :: Zeigt die Commit-Historie kompakt als Grafik an
git branch :: Listet alle Branches auf und zeigt, auf welchem du bist
git checkout -b branchname :: Erstellt einen neuen Branch und wechselt direkt dorthin
git merge branchname :: Führt einen anderen Branch in deinen aktuellen Branch zusammen
git stash :: Legt aktuelle Änderungen kurz beiseite ("in den Schrank"), um sauber zu arbeiten
git stash pop :: Holt die beiseitegelegten Änderungen aus dem Schrank zurück
git remote -v :: Zeigt an, mit welchem Server (URL) dein Repository verbunden ist
